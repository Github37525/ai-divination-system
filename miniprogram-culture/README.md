# 周易经典研习小程序

公开提审候选工程。产品定位是传统文化经典阅读，不包含个性化问题输入、随机生成、传感器触发、模型解释或完整互动体验入口。

## 运行

1. 用微信开发者工具导入本目录。
2. 将 `project.config.json` 中的 `touristappid` 替换为公开文化版的实际 AppID。
3. 运行 `node ../scripts/build_miniprogram_culture_data.js` 可从经过核验的主数据库重新生成小程序数据包。
4. 预览并检查 64 卦搜索、详情、阅读术语及来源页面。

该工程不发起网络请求，不需要配置服务器域名，也不需要任何模型密钥。提交审核前仍应以微信公众平台当期规则进行人工内容复核。
