# iOS / Android 真机验收清单

模拟器只能验收页面和 API，以下项目必须在真机完成。每台设备完成一轮“新建问题 → 六次摇动 → 盘面锁定 → DeepSeek 解读 → 杀进程后恢复”。

## 设备矩阵

| 平台 | 低档/旧设备 | 主流设备 | 高刷/高触觉设备 |
| --- | --- | --- | --- |
| iOS | iPhone 11 / iOS 17 | iPhone 14–16 | ProMotion + Core Haptics 设备 |
| Android | API 26–29、仅基础振动器 | API 33–36 主流机 | 支持 haptic primitives 的 Pixel/旗舰机 |

## 动作与状态

1. 进入摇卦页后保持手机平稳，约 0.5 秒完成校准；文字必须从“校准中”变为“已就绪”。
2. 轻微日常移动不能误触发；900ms 内达到三次有效脉冲才触发一爻。
3. 触发后立即显示“感应动作”，网络确认后显示“结果已锁定”，再开始铜钱动画。
4. 断网时不能伪造爻；显示可重试错误，恢复网络后仍是同一爻位。
5. 切后台必须停止传感器；回前台重新校准，不能在口袋中连续起爻。
6. 无陀螺仪、无加速度计或传感器被系统限制时，点按起爻必须可用。

## 视觉、声音与触觉

1. 三枚铜钱的撞击点与三次触觉/音效顺序一致；一爻锁定时为双短反馈。
2. 老阴、老阳增加一次更重的末端反馈；少阴、少阳没有这次重击。
3. 六爻完成使用成功反馈，不能与普通一爻完全相同。
4. 音效首次安装默认关闭；开启动作必须由用户主动完成，并允许随时静音。
5. 关闭触觉后全流程不再调用振动；不支持高级原语的 Android 自动降级且不产生刺耳长震。
6. 系统“减少动态效果/移除动画”开启后，铜钱直接短过渡到结果，信息和触觉状态不丢失。

## 恢复与一致性

1. 完成第 1、3、5 爻后分别杀进程，重新打开应恢复到最后已锁定节点，不再次随机。
2. 第六爻完成后立即杀进程，重新打开应继续确定性排盘或解读轮询。
3. 同一会话的 `run_id`、六个 `value`、本卦、变卦与 H5 返回一致。
4. 过期或无效 token 必须清理本机凭证并允许重新开始；token 不写入日志或普通明文偏好。

## 性能记录

- 有效动作到首个视觉反馈 P95 ≤ 80ms。
- 有效动作到轻触觉 P95 ≤ 60ms。
- 动画目标 60fps；记录最差帧、机身温升和 10 分钟连续使用电量。
- 录屏无法记录触觉，验收表需由测试者单独填写“过轻/清晰/过重”。
