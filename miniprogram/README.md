# 数智易学内部体验小程序

> 内部研发体验版：只用于管理员、开发者和白名单体验成员进行真机测试，不提交公开审核，不作为转发运营渠道。

该目录是原生内部体验客户端，直接复用生产环境的 FastAPI、Redis 与 DeepSeek 异步解释服务。小程序内不保存任何模型密钥，也不在本地生成卦象结果。公开文化学习版位于 `../miniprogram-culture`。

## 本地运行

1. 打开微信开发者工具，导入本目录。
2. 将 `project.config.json` 中的 `appid` 从 `touristappid` 替换为内部研发使用的小程序 AppID。
3. 开发调试阶段可在开发者工具中临时关闭“校验合法域名”；真机和上线前必须在微信公众平台把 `https://ai-divination-experience.onrender.com` 加入 `request` 合法域名。
4. 选择真机调试，验证体感摇卦和震动。开发者工具无法准确模拟真实传感器与触觉反馈。

API 地址集中配置在 `app.js` 的 `globalData.apiBaseUrl`。

## 当前范围

- 独立填写占问事项并创建安全会话
- 点按或手机加速度传感器摇出六爻
- 每爻震动与铜钱反馈动画
- 本地会话凭证保存、退出重进恢复进度
- 确定性盘面即时展示、DeepSeek 结果异步轮询
- 最多 20 条本机历史卦例

该工程不安排公开发布能力。微信登录、云端历史及电脑二维码联动仅在内部研发确有需要时继续建设。
