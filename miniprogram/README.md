# 数智易学微信小程序

该目录是原生微信小程序客户端，直接复用生产环境的 FastAPI、Redis 与 DeepSeek 异步解释服务。小程序内不保存任何模型密钥，也不在本地生成卦象结果。

## 本地运行

1. 打开微信开发者工具，导入本目录。
2. 将 `project.config.json` 中的 `appid` 从 `touristappid` 替换为实际小程序 AppID。
3. 开发调试阶段可在开发者工具中临时关闭“校验合法域名”；真机和上线前必须在微信公众平台把 `https://ai-divination-experience.onrender.com` 加入 `request` 合法域名。
4. 选择真机调试，验证体感摇卦和震动。开发者工具无法准确模拟真实传感器与触觉反馈。

API 地址集中配置在 `app.js` 的 `globalData.apiBaseUrl`。

## 当前范围

- 独立填写占问事项并创建安全会话
- 点按或手机加速度传感器摇出六爻
- 每爻震动与铜钱反馈动画
- 本地会话凭证保存、退出重进恢复进度
- 确定性盘面即时展示、DeepSeek 结果异步轮询
- 最多 20 条本机历史卦例

微信登录、云端历史、订阅消息以及电脑二维码直达小程序，需要实际 AppID、AppSecret 和微信公众平台权限，后续接入。
