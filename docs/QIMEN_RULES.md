# 奇门排盘规则约定与核验来源

本项目固定采用“时家转盘奇门·拆补法”。结果中显式保存流派、定局法及中宫寄宫约定，不把不同流派规则混合为一个所谓唯一答案。

- 阴阳遁和二十四节气上中下元局数表：参照公版古籍《遁甲演义》及现代机械排盘表交叉核验。
- 三奇六仪、六甲旬首、值符值使、九星八门八神：采用洛书九宫机械飞布；解释性吉凶断语不进入算法层。
- 中宫约定：阳遁寄艮八、阴遁寄坤二，天禽随天芮。
- 八神顺序固定为值符、螣蛇、太阴、六合、白虎、玄武、九地、九天；神盘按阳顺阴逆转布。
- 参考基准盘：MIT 许可的 [3meta](https://github.com/3metaJun/3meta) 测试用例 `2008-11-04 12:30`（霜降、阴遁二局），用于交叉验证值符、值使和关键宫位。实现代码为本项目独立 Python 实现。
- 古籍影像入口：[遁甲演义（维基共享资源）](https://commons.wikimedia.org/wiki/File:CADAL06056497_%E9%81%81%E7%94%B2%E6%BC%94%E7%BE%A9%C2%B7%E5%8D%B7%E4%B8%89~%E5%8D%B7%E5%9B%9B.djvu)。

终身盘的大运入口采用“阳男阴女顺、阴男阳女逆，三日折一年”约定。五行分布只统计四柱八个显性干支，不伪装成统一的吉凶评分。
