## 完成定义

1. 所有表格项达到“完成”。
2. 不依赖网络的测试在无密钥环境全部通过。
3. DeepSeek 使用注入式假客户端完成协议测试；提供密钥后再做真实调用冒烟测试。
4. 问事奇门、终身盘与六爻至少各有独立基准盘和边界测试。
5. 审计、反馈、历史查询完成临时数据库端到端测试。
6. `compileall`、依赖检查、全量测试、性能门禁和 Streamlit 启动检查全部通过。
